Coral Bay: Wheelman — an original top-down 2D open-world crime game in the browser. Explore a seeded coastal city on foot and by car: steal and drive 8 vehicle types, run a 5-mission story chain for fixer Delia Voss, take courier jobs, and face a witness-based 0–5 star police response — interceptors, foot chases, a bust meter — or escape by boat. Vanilla JavaScript on canvas with WebAudio-synthesised sound, a full HUD with minimap, and a localStorage save system.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD and mouse to play, E interacts, Esc pauses, M mutes.

## Controls

- **WASD / arrows** — walk or drive
- **Mouse** — aim, **click** — shoot
- **E** — enter or leave a car, talk, buy food
- **Shift** — handbrake (drift)
- **R** — reload · **Esc** — pause · **M** — mute
